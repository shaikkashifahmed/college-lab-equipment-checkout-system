LabDesk - Lab Equipment Checkout System (Python + Tkinter GUI)

HOW TO RUN
1. Install Python 3.9 or newer (tick "tcl/tk and IDLE" during setup on Windows).
2. Keep labdesk.py and model.py in the same folder.
3. Optional, for QR code images:  pip install qrcode pillow
4. Run:  python labdesk.py
